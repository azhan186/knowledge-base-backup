# 楼层清洁与铺床标准（Floor_Merged_001）

> **LSOP No.**: RM-HSKP-Floor_Merged_001 | **类别**: 楼层（Floor/Housekeeping） | **生效日期**: 2019-08-08
> 编制：服务总监 | 批准：总经理
> 由 Floor_003 / 013 / 019 / 020 / 026 / 027 / 028 / 029 合并整理

## 摘要

为酒店建立一个制度，以鉴定需清洁的区域或某一物品应达到要求的水平和质量标准。酒店所有提供清洁服务的相关员工将被培训，以使他们的清洁工作能达标并超越下列的清洁标准。同时覆盖客房清洁流程、关门打扫礼仪、铺床标准、浴室清洁、吸尘器使用、公共区域清洁及优先打扫排序,形成完整的楼层清洁与铺床标准体系。

## 目的

- 确保任何时候酒店清洁工作的持续性及质量标准（来源：Floor_003）
- 确保在客房清洁工作进行当中客房门的安全性（来源：Floor_013）
- 楼层公共区域连同服务区及紧急楼梯清洁卫生（来源：Floor_019）
- 维护吸尘器良好状态（来源：Floor_020）
- 为所有住店客人提供始终如一的客房清洁服务（来源：Floor_026）
- 客人回来之前准备"洁净、舒适、准备睡觉"的床（来源：Floor_027）
- 客人到来时提供洁净、卫生的洗手间（来源：Floor_028）
- 优先清洁空房/离店房，减少客人等候时间（来源：Floor_029）

## 政策规定

1. **清洁标准统一**:酒店清洁标准必须明确，并培训所有员工达标
2. **关门清洁规范**:客人在与不在时，操作流程不同
3. **公共区域检查**:楼层公共区域、服务区、紧急楼梯一天检查三次
4. **设备保养**:员工有责任保持吸尘器的良好状态
5. **一致服务品质**:确保客房清洁标准被执行
6. **安全作业**:确保酒店财产被很好地维护，以达到最佳表现，同时有助于人身安全
7. **铺床标准**:确保服务品质一贯性
8. **浴室清洁标准**:确保清洁标准一贯执行
9. **优先打扫**:尽量将所有离店房及空房在下午前清洁完毕，减少客人等候时间（特别是高住房率时）

## 二、客房清洁流程

**来源**: Floor_026《房间清洁》

1. 按门铃3次，在进入客房前等几秒钟让客人反应。
2. 将清洁篮拿进客房。
3. 打开所有窗帘（让阳光照进来 / 看窗帘是否完好）。
4. 客房服务员应该进行快速的视觉检查整个房间，确保没有不合适的设备，如摄像头。
5. 检查所有的灯，如有灯泡损坏应更换，报修所有坏灯。
6. 将送餐服务的托盘移至员工梯处。检查是否有客人物品留下。
7. 清理所有垃圾并装进垃圾袋。
8. 将需更换的被子及枕头放在沙发上，将床单拿走（确认拿走床单时没有客人物品夹在当中）。
9. 开始做床。

### 除尘程序（按顺序顺时针或逆时针）

为避免疏漏，更简单的方法是顺时针或逆时针从客房门开始，有次序地绕客房打扫，最后在房门结束。

- **门**:房号牌，门锁，门框（如果够不着可使用梯子）
- **壁橱**:门，架子，衣架，挂衣杆及行李架
- **冰箱**:顶部及底部
- **画像及电视柜**:所有边框及表面，电视柜的抽屉
- **电视机**及其下部
- **写字桌，镜子，抽屉，台灯，灯罩**
- **窗台**，特别是窗帘后的部分

## 三、关门打扫标准

**来源**: Floor_013《客房服务员关门打扫房间的标准》

### 客人不在房间内

1. 客房门在清扫过程中必须保持关闭。
2. 客房服务员在做房间时必须将工具及物品放在房间里面。
3. 在门把手上挂"悉心打扫"的牌子，表明工作正在进行中。

### 客人在房间内

1. 如果客人在房间，客房门必须保持开启。
2. 如果客人有异议的，员工需及时解释。
3. 如果服务员打扫时客人有不当行为，客房服务员应该立即离开房间并及时报告。
4. 当客房服务员开关客人房门时，客人要进入客房，客房服务员必须试客人的房卡并询问何时再方便打扫。确认时间后客房服务员应及时离开房间，在规定的时间内返回。
5. 如果客人要求服务员继续打扫时，客房门必须保持开启。
6. **在任何情况下，每当客房服务员与客人或第二同事在一起时，客房门必须保持开启**。

### 客人要求开门

如果有客人要求客房服务员打开房门, 是因为他们丢失了钥匙或很难打开门，客房服务员要礼貌地请客人，直接到前台办理新的房卡并打电话给办公室。

### 重要备注

- **无论何时离开客房时，门必须安全关上**。无论是到备品间拿备品，或是完全离开房间，你必须确保门是安全关上的。
- **当发现客房门是开的时不要进入**！立即敲门并查看是否有客人，如果客人不在房内，关门并通知客房部办公室文员。办公室文员再通知大堂经理及保安部当班主管。员工在未接到任何指示前，不得进入房间打扫。

## 四、铺床标准

**来源**: Floor_027《铺床》

### 程序

1. 将被子从床上移走放在沙发上。
2. 将枕套取下。
3. 将床单取下并确保里面没有客人物品（所有脏布草撤出之前,都必须抖一下）。
4. 将脏布草放到员工电梯厅的脏布草推车内。
5. 将床拉出一些，拿出一套与床尺码和床数相同的床单及枕套。
6. 调整床垫及弹簧垫到正确的位置。
7. 拉直床垫上的衬垫，如有污迹应更换。
8. 将床单铺在床上，先将床头位置的床单塞在床垫下，然后将床单边角斜折直角塞进床垫两侧下，最后将床尾的床单塞到床垫下。
9. 床单边角斜折成90，然后塞在床垫两侧。
10. 将被子连同被单铺到床上。
11. 将枕头套上枕套并靠床头板放好。
12. 最后检查确保被子均匀地铺在床上。
13. 将床推回原处。

### 铺床标准

| 部位 | 标准 |
| --- | --- |
| 床单 | 床单——正面朝上，中线对正（两边无偏差） |
| 包角 | 90度包角，直挺不松，四边包紧不松 |
| 整体 | 包紧且挺 |
| 被套头部 | 饱满，上下齐全，外延挺括 |
| 被套两侧 | 被子边缘与被套边缘对齐无皱褶 |
| 被套尾部 | 被子不在床垫上回缩，上下平整单齐，两个自然下垂 |

## 五、浴室清洁

**来源**: Floor_028《浴室清洁》

### 程序

1. 在清洁工作开始前，首先检查清洁剂瓶是否装满，标签是否正确。
2. 将清洁桶拿到洗手间。
3. 清理垃圾和脏布草，将其分别移至垃圾袋和员工梯区域。
4. 将脏的杯具收出送至工作间。
5. 冲洗抽水马桶，喷洒清洁剂在里面，等待清洁剂起化学作用。
6. 清洗冰桶，将它们倒置让水滴下。
7. 将清洁剂喷入洗脸池，使用擦洗垫彻底清洁包括排水塞，水龙头，皂碟及大理石台等位置, 然后用水冲洗并滴干。
8. 喷洒清洁剂在浴缸或淋浴间，墙面瓷砖处，然后用擦洗垫擦洗。擦洗浴帘，淋浴头，瓷砖，水龙头，排水孔及排水塞。用水冲洗然后晾干。
9. 同时使用干净抹布和擦玻璃布。从洗手池区域开始。如有污迹用擦玻璃布擦亮镜子。
10. 抹布—擦干洗手池，水龙头，皂碟及大理石台，擦亮所有物品。
11. 擦干淋浴头，浴帘，马桶及浴缸。
12. 擦干马桶盖，马桶及下面。不要忘记马桶盖铰链。
13. 擦干净垃圾桶。
14. 从里到外擦净地面。
15. 从工作间拿干净的杯具补入房间。
16. 将物品放回原处。替换客用品并挂好毛巾。
17. 最后检查一下看有无遗漏。

### 备注

- **不允许在房间内清洗玻璃器皿和瓷器**，所有的玻璃器皿和瓷器只可以在工作间清洗并消毒，并用粉条纹口布抛光清洁。
- **五色抹布规范**:红色抹布清洁马桶，绿色清洁面盆，蓝色冲淋房和浴缸，黄色抹灰，大浴巾地面，蓝色镜布清洁窗玻璃及镜子。

## 六、吸尘器使用

**来源**: Floor_020《使用吸尘器》

### 程序

1. 在使用前检查插头、软管、尘袋、吸尘系统。看是否有地方松动或损坏。
2. 将插头插入离门最近的插座，放开电线，将机器移到房间角落，打开窗帘，捡起较大的垃圾。
3. 打开机器从由里向外一行一行吸尘，避免遗漏。确保家具下被打扫到，并向门的方向倒退着作业以防止留下脚印。
4. 发现污渍立即去除（也可以记录下来吸完再去渍）。
5. 吸尘时发现异常情况（机身热、异声、异味、吸力弱）立即停止，并报告主管。
6. **不可吸水或玻璃碎片**，以免损伤电机或尘袋。
7. 挺直背。
8. 在清洁时，不要用力拉吸尘软管和电线，避免损坏接口和插头。
9. 每天清空吸尘袋，然后清洁机器。
10. 定期对吸，清洁吸尘扒头，并用抹布擦滚筒内壁和电线。
11. 除编码外，吸尘器表面不得有任何张贴物。

## 七、楼层公共区域清洁

**来源**: Floor_019《清洁楼层公共区域》

### 客区

1. 使用吸尘器清洁走廊，特别注意角落及边缘地带，小心不要在脚板，墙面，门及门框处留下印记。
2. 将送餐服务手推车，托盘或器皿送到服务电梯升降台。
3. 检查脚板，墙面，门及门框处有无污点。使用微湿的黄色干净抹布清洁。
4. 使用微湿的黄色干净抹布将走廊上的所有表面的灰尘去除掉（包括客用电梯内部及其设备）。
5. 使用喷洒窗户清洁剂的干净蓝色抹布清洁所有镜子及玻璃（包括玻璃艺术品）。确保所有镜子，玻璃及艺术品的框被清洁。
6. 在晚间检查走廊时重复上边的所有步骤。
7. **注意：晚6点以后不得进行吸尘工作**，客人走廊上无送餐服务手推车，托盘及器皿的滞留。
8. **周一至周五的上午9点前及周六周日的上午10点前不要在客人走廊进行吸尘工作**（观察"请勿打扰"指示牌，确保睡觉客人的舒适性）。
9. 一天两次给走廊吸尘，包括地毯的边缘部分。
10. 楼层服务员上楼层第一时间，巡视楼层客梯厅及走道，并在早上9点开始吸尘。
11. 一天最少三次检查走廊有无纸屑垃圾（早上、午饭后及下班之前）。

### 后区

1. 一天一次，使用干净拖把和水清洁服务区。
2. 一周两次用干净拖把和水清洁所有楼梯，清洁时根据需要换水洗拖把。
3. 一天两次检查楼梯上有无纸屑，拣拾清理垃圾。
4. 一周三次清扫楼梯，从上至下。
5. 一天一次为公共区域铺地毯的楼梯吸尘。
6. 不在服务区域存放餐饮部的食品和酒水。
7. 不得将拾到的物品放在楼层工作间内，应将拾到的物品及时送至管家部办公室。
8. 所有布草和客用品都放在指定的架子上，按逻辑工作流摆放。

## 八、优先打扫排序

**来源**: Floor_029《优先打扫》

### 排序规则

1. **优先清洁空房或离店房**，以便为客人入住提供可用的"准备好"的房间。
2. 客房部文员会在早晨分配当日优先打扫房间。
3. 打印抵店报告，注明从前厅部得到的将住客房的房型。
4. 运用单独的"VD-脏空房"报告作为检查的参照。
5. 将上述信息交所在楼层主管负责处理。
6. 如有大量提前抵店客人或离店客人同时出现，楼层主管的责任是改变房间以使它们被及时打扫。
7. 在房间清洁完并检查后，楼层主管应向办公室报告以确保房态更新。
8. **所有早上接到通知的贵宾预到房必须在中午12点前清洁完毕**。
9. **所有住客房及贵宾住客房必须在下午4点前清洁完毕**。
