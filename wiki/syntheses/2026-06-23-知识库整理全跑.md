### 🎁 顺手发现：挂载点等价

清理过程中挖到的**架构真相**：

```bash
$ mount | grep workspace
/dev/mapper/ug_8E91A3_1778565269_pool1-volume1 on /root/.openclaw type ext4
/dev/mapper/ug_8E91A3_1778565269_pool1-volume1 on /root/.workspace.old type ext4
/dev/mapper/ug_8E91A3_1778565269_pool1-volume1 on /home/azhan186/open claw type ext4
/dev/mapper/ug_8E91A3_1778565269_pool1-volume1 on /root/.openclaw/workspace type ext4

$ stat -c "%i" /root/.openclaw/workspace /home/azhan186/open\ claw
118751238  /root/.openclaw/workspace
118751238  /home/azhan186/open claw  # 同 inode！
```

**含义**：
- `$WORKSPACE/memory` ≡ `/home/azhan186/open claw/memory`（物理上是同一份数据）
- `memory-cleanup.sh` 用的 `$WORKSPACE/memory` 本来就等价于 A，**不用改**
- 路径"不一致"只是符号层面

**B/C 是真正独立的子目录**（在 `/home/azhan186/open claw/知识库/` 下），所以删除是正确的。
