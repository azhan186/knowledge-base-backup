## 三、v2.2 架构设计

### 3.1 数据流

```
主人(飞书消息)  ──>  我(AI)  ──>  写 .md 到 wiki/  ──>  重编 graph.json/index.html  ──>  浏览器(只读繁星)
   [输入]            [编辑器]         [数据]                  [编译]                          [展示]
```

**关键约束**：
- 浏览器端**只读**（不编辑）
- 编辑入口 = 飞书消息
- 编译 = AI 助理 + cron + 心跳机制（已存在，AGENTS.md 协议）

### 3.2 节点层级结构（递归嵌套散点）

```
L1: 11 颗大星
    ├─ "生活" 在画布中心 (0, 0)
    └─ 其他 10 颗散在 "生活" 周围 (r ∈ [400, 800])

L2: ~30 颗中等星
    └─ 散在各自 L1 内 (r ≤ 80)

L3: ~18 颗小星
    └─ 散在各自 L2 旁 (r ≤ 30)

L4: 750+ 颗最小星
    └─ 散在各自 L3 旁 (r ≤ 12)

边：仅 L4 之间画关联线（v1.0 backlinks 已有数据，1696 个 wikilink）
```

### 3.3 节点大小与颜色

| 层级 | 节点半径 | 颜色 |
|------|----------|------|
| L1 | 25 px | 按 L1 学科（11 色） |
| L2 | 12 px | 继承 L1 父节点色 |
| L3 | 6 px | 继承 L1 祖先色 |
| L4 | 3 px | 继承 L1 祖先色 |

### 3.4 LOD 切换（4 档）

| k 范围 | 显 |
|--------|------|
| k < 0.4 | 全隐（极远） |
| 0.4 ≤ k < 0.6 | L1 |
| 0.6 ≤ k < 0.85 | L1 + L2 |
| 0.85 ≤ k < 1.10 | L1 + L2 + L3 |
| 1.10 ≤ k ≤ 1.50 | L1 + L2 + L3 + L4 + 边 |
