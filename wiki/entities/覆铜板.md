# 覆铜板（CCL）

## 核心信息

- **全称**：覆铜箔层压板（Copper Clad Laminate，CCL）
- **别名**：覆铜板、基板
- **性质**：PCB 制造的**核心基材**
- **地位**：PCB 产业链中游，**涨价传导的枢纽**

## 构成

CCL 由三大主材**复合压制**而成：

```
   铜箔（导电层）
   ↓
   树脂（粘结+绝缘）  ← 环氧树脂 / PPE 树脂 / 酚醛树脂
   ↓
   电子布（增强骨架）  ← 玻璃纤维织造
   ↓
   铜箔
```

简化公式：**CCL = 铜箔 + 树脂 + 电子布（玻纤布）**

## 主要分类

| 分类维度 | 类别 | 典型应用 |
|----------|------|----------|
| **按基材** | 玻纤布基（最常见） | 通用 PCB |
| | 纸基 | 低端消费电子 |
| | 复合基 | 家电 |
| **按性能** | 高速 CCL | AI 服务器、5G 基站 |
| | 高频 CCL | 雷达、卫星 |
| | 高 Tg / 高耐热 | 汽车电子 |
| | 普通 FR-4 | 消费电子 |
| **按刚性** | 刚性 CCL | 主流 |
| | 挠性 CCL（FPC） | 折叠屏、可穿戴 |

## 涨价链中的角色

CCL 是 PCB 产业链**涨价传导的关键节点**：

```
电子布涨价 + 铜箔涨价 + 树脂涨价
    ↓
CCL 成本上升（原料占总成本 60-80%）
    ↓
CCL 提价
    ↓
PCB 整机成本上升
    ↓
PCB 终端涨价 / 板块异动
```

**典型案例**：
- 2026-06-08：电子布年内 5 轮提价涨幅 100%，CCL 企业原料库存从 1.5 月压到 7 天
- 2026-06-09：CCL 龙头**金安国纪**涨停（[[../../sources/文学/新闻传播学/时政新闻/source-2026-06-09-PCB概念股批量涨停]]）

## 关键术语

- **Tg（玻璃化转变温度）**：衡量 CCL 耐热性能，**Tg 越高越贵**
- **Dk / Df**：介电常数 / 损耗因子，**高速 CCL 核心指标**
- **CTE（热膨胀系数）**：与芯片匹配，影响可靠性
